# YET driver app (Flutter, Android-first)

Phase 0 scope: PDPP consent screen (Amharic + English), permissions explainer, trip
screen shell. Phase 1 adds background GPS, drift/SQLite cache with the sync state
machine, and the batch uploader.

## Build prerequisites (workstation, not this repo container)

```bash
flutter --version            # >= 3.22
flutter config --enable-android
cd driver-app
flutter gen-l10n             # generates lib/l10n/app_localizations.dart from ARB files
flutter pub get
flutter analyze && flutter test
flutter run                  # debug build talks to http://10.0.2.2:3000 (host backend)
```

`lib/l10n/app_localizations.dart` is generated by `flutter gen-l10n` and intentionally
not committed. Amharic strings live in `lib/l10n/app_am.arb`.

## Android manifest requirements (added with geolocator in Phase 1)

- ACCESS_FINE_LOCATION, ACCESS_BACKGROUND_LOCATION ("Allow all the time" — see
  permissions_screen.dart copy explaining why)
- FOREGROUND_SERVICE_LOCATION + persistent notification (battery-gated tracking)
- REQUEST_IGNORE_BATTERY_OPTIMIZATIONS (guided in Phase 4 hardening)
- minSdk 26 (Android 8), target newest stable — runs acceptably on Android 10/2GB RAM (§1.2)

## Offline contract code anchors

- `lib/core/cache/sync_state.dart` — frozen state machine + no-data-loss tests (`test/`)
- `lib/core/config/app_config.dart` — batch size 100, backoff cap 5min, storage caps 80/100MB
